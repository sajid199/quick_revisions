5. Greenfield vs Brownfield

Brownfield (conversion)

Keep existing roles and fix them.

  1. Run SU24_AUTO_REPAIR
  2. Run SU25D, share which roles are affected
  3. Share PRGN_CORR2 and PROFGEN_CORR_REPORT_2 reports
  4. Review call with business, record decisions
  5. SU25 2a / 2b / 2c
  6. SU25 step 3: capture in TR

Greenfield (new install)

Start fresh and design roles properly.

  1. SU25 step 1
  2. SU25 2a / 2b / 2c
  3. SU25 step 3: capture in TR
  4. Copy SAP roles to Z roles for functional team
  5. Role design discussion, then role creation
  6. Test IDs, UAT, go-live, hypercare
